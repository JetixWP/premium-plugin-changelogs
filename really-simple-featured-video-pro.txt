Really Simple Featured Video Pro extends original RSFV plugin support for Featured video to WordPress posts, pages, WooCommerce Products and CPTs.

== Description ==

= Video Studio PRO =

Video Studio auto generates featured videos from templates. PRO needs the free plugin with Video Studio, and adds:

* Auto generate videos from 20 more templates for all kinds of sites (free has 7):
  * Shops: Sale, Coupon code, Product showcase
  * Blogs and news: Top list, Podcast episode
  * Food: Recipe, Menu board
  * Business: Visit us, Property listing, Course, We're hiring, App feature
  * Photos: Destination, Before and after, Portfolio grid, Lower third
  * Events and brand: Event, Countdown, Stats counter, Logo reveal
* More sizes: 9:16 (Stories, Reels, Shorts), 4:5, 1080p at 60 fps and 4K (free has 16:9 and 1:1)
* Music: pick a track from the Media Library, with volume, fade in and out, start point and repeat
* Brand kit: save colors, a font and a logo once, and new videos start with them
* Big uploads: videos larger than your host's upload limit are sent in pieces
* Auto generate videos in bulk: tick entries on the Video Studio page and use Make videos to create a video for each one, filled from it
* Platypi, Beiruti and Fira Code fonts (SIL Open Font License 1.1), see assets/studio/fonts/LICENSE.txt
* Google Fonts: every Google Fonts family with Latin letters can be picked in templates. The first time one is used, your site downloads its font files from Google Fonts and keeps them in uploads/rsfv-studio-fonts; after that they load from your site. Fonts are only used while making the video (the text becomes part of the video), so visitors never load them

== Installation ==

This section describes how to install the plugin and get it working. e.g.

1. Upload the plugin files to the `/wp-content/plugins/rsfv-pro` directory, or install the plugin through the Plugins >> Add new screen directly.
2. Activate the plugin through the 'Plugins' screen in WordPress.
3. Head to '[Pro] Really Simple Featured Video' page from WordPress sidebar menu.

== Frequently Asked Questions ==

= Will this plugin work with any theme? =
Yes, as long as the theme you use follows standard WordPress/WooCommerce way of handling post thumbnails, this plugin should work without any problems.

= Where can I get help? =
You can get help by reaching out to me at https://github.com/JetixWP/really-simple-featured-video or support forums here.
